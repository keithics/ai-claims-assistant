# 保険金請求の手順

カラヤアン・ミューチュアル日本は、自動車・医療・住宅の保険金請求を扱います。

1. 事故の日から**60日以内**にご連絡ください。
2. 必要書類のご案内に沿って書類をご用意ください。
3. アシスタント、アプリ、またはコールセンターからご請求ください。
4. 請求の下書きを作成します。ご自身で内容を確認し、承認してから提出されます。アシスタントが自動で請求を提出することはありません。
5. 書類がそろってから**30日以内**のお支払いを目標としています。

こちらはAIアシスタントです。いつでも担当者への引き継ぎをご依頼いただけます。
