# Status klaim dan berbicara dengan petugas

Tanyakan status klaim kepada asisten dengan nomor klaim, misalnya format `ID-1042`. Pembaruan status bisa memakan waktu karena sistem klaim kami lambat pada jam sibuk.

Anda dapat meminta agen manusia kapan saja dan keluhan ditangani pusat layanan telepon. Klaim di atas batas pada jadwal polis selalu ditinjau oleh petugas.
