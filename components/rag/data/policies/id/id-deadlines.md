# Batas waktu klaim

- Laporkan kejadian dalam **7 hari** sejak kejadian.
- Kirim semua dokumen pendukung dalam **21 hari** sejak kejadian.
- Klaim yang disetujui dibayar dalam **14 hari kerja** setelah dokumen lengkap diterima.

Laporan terlambat dapat ditolak kecuali ada alasan yang wajar.
