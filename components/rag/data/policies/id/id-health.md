# Klaim rawat inap dan kesehatan

- Masa tunggu **45 hari** berlaku untuk polis kesehatan baru, kecuali kecelakaan.
- Untuk rawat inap terencana dengan perkiraan biaya di atas **Rp 10.000.000**, minta persetujuan awal sebelum masuk rumah sakit.
- Rawat inap darurat: beri tahu kami dalam 48 jam.
