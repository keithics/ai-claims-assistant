# Klaim kendaraan

- Risiko sendiri (bagian yang Anda bayar) adalah **Rp 300.000** per klaim.
- Ambil foto lokasi dan kerusakan sebelum memindahkan kendaraan jika aman.
- Di Indonesia, laporan polisi diwajibkan untuk pencurian dan kerugian di atas Rp 5.000.000.
- Jangan menyetujui perbaikan sebelum kami mengonfirmasi klaim, kecuali kendaraan tidak aman ditinggalkan.
