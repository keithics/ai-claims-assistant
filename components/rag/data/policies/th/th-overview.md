# วิธียื่นเคลม

Kalayaan Mutual ประเทศไทย ดูแลเคลมรถยนต์ สุขภาพ และที่อยู่อาศัย

1. แจ้งเหตุภายใน **15 วัน** นับจากวันเกิดเหตุ
2. เตรียมเอกสารตามคู่มือเอกสารที่ต้องใช้
3. ยื่นเคลมผ่านผู้ช่วย แอป หรือศูนย์บริการทางโทรศัพท์
4. เราจัดทำร่างเคลมให้ คุณต้องตรวจสอบและอนุมัติก่อนยื่น ผู้ช่วยไม่ยื่นเคลมเอง
5. เมื่อได้รับเอกสารครบถ้วน เรามุ่งจ่ายเงินภายใน **20 วันทำการ**

คุณกำลังคุยกับผู้ช่วย AI สามารถขอคุยกับเจ้าหน้าที่ได้ทุกเมื่อ
