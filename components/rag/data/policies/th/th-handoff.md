# สถานะเคลมและการติดต่อเจ้าหน้าที่

ถามสถานะเคลมจากผู้ช่วยด้วยหมายเลขเคลม เช่น รูปแบบ `TH-1042` การอัปเดตสถานะอาจใช้เวลาเพราะระบบเคลมของเราช้าในช่วงเวลาที่มีผู้ใช้มาก

คุณขอคุยกับเจ้าหน้าที่ได้ทุกเมื่อ และข้อร้องเรียนจัดการโดยศูนย์บริการทางโทรศัพท์ เคลมที่เกินวงเงินในตารางกรมธรรม์จะมีเจ้าหน้าที่ตรวจสอบเสมอ
