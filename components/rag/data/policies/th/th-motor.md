# เคลมรถยนต์

- ค่าเสียหายส่วนแรก (ส่วนที่คุณจ่ายเอง) คือ **1,500 บาท** ต่อเคลม
- ถ่ายรูปที่เกิดเหตุและความเสียหายก่อนเคลื่อนย้ายรถหากปลอดภัย
- ในประเทศไทย ต้องมีใบแจ้งความจากตำรวจสำหรับอุบัติเหตุทุกครั้ง
- อย่าอนุมัติการซ่อมก่อนที่เรายืนยันเคลม เว้นแต่รถไม่ปลอดภัยที่จะทิ้งไว้
