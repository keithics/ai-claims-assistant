# สิ่งที่ไม่คุ้มครอง

สิ่งต่อไปนี้ไม่คุ้มครองในประเทศไทย:

- ความเสียหายจากน้ำท่วม เว้นแต่กรมธรรม์มีความคุ้มครองน้ำท่วม
- การใช้รถเป็นรถแท็กซี่หรือรถรับจ้างที่ไม่ได้แจ้งไว้
- ความเสียหายขณะผู้ขับขี่เมาสุราหรือไม่มีใบอนุญาตขับขี่

โปรดตรวจสอบเงื่อนไขกรมธรรม์เพื่อดูรายการทั้งหมด
